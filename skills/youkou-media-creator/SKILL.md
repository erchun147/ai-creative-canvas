# 专属创作 Skill 与本地画布

使用前阅读仓库 LICENSE。软件的出售、收费托管或未经授权贴牌经营受限；生成作品按平台/模型规则，正式书面授权代理只在授权范围内例外。

## 先判断是否已经接入

先读取本人已保存的非敏感安装回执或 profile.json 路径；新对话从当前 Agent 实际发现的 Skill 目录读取安装定位，不扫描其他账号。没有账号配置时，明确告诉用户按四步完成：

1. 打开 https://erchun.youkou.cc 注册并登录。
2. 打开「开放 API」的一键 AI 对接页面：https://erchun.youkou.cc/user/open-api#api-ai-connect。
3. 点击「复制接入命令」。不要求用户手动复制 API Key。
4. 把该命令发给当前 AI，继续接入。

可运行仓库 scripts/onboard.py 查看指引。用户已从合法贴牌站获取命令时保持其原站点，后续使用绑定站点和原API，不改回默认主站。没有终端/文件权限的网页AI应说明不能直接安装本机工具。

## 收到网站命令后

- 先检查Windows/Mac、架构、Python3、受支持Node LTS、浏览器和本人目录权限。scripts/onboard.py --doctor只做检测。缺环境时说明官方来源、下载内容和占用，优先本人目录，核验可用校验/签名；管理员/受管设备/离线边界请用户处理，不覆盖系统环境。预构建包不需要npm install或浏览器扩展。
- 接入命令包含一次性码。只向命令原始HTTPS站点发送一次，把成功响应先完整保存到本人私有临时文件，再读取；禁止循环尝试其他域名、覆盖成功响应或把超时当成可重复领取。原命令丢失/过期请回原页面复制，不猜接口。
- 使用收到的真实说明和临时credential配置。先审阅 scripts/client-installer.py，复制到稳定的本人工具目录后，通过标准输入传入临时配置；不要curl回显credential接口。它按原协议领取并保存本人Key，输出不含Key的profile_path。临时码不进Skill/日志/版本库，成功后删除该临时配置；Key只由CLI在进程内读取本人私有文件，不进钥匙串、聊天、前端或子Agent消息。
- 收到旧说明时仍保留本仓库的凭据隐私要求，不重复创建密钥或迁移到钥匙串。契约未满足时停止并说明，不能按猜测读取凭据。

## 安装本机Skill并启动画布

先用已审阅客户端的 --update <profile.json绝对路径>检查官方规则；接口可用就核验并使用实际下载规则。若404/网络失败，保留已领取凭据，不重复消费接入码；可明确安装本仓库附带、版本已标识的离线规则，运行：

```text
python scripts/onboard.py --profile <profile.json绝对路径> --install-bundled-skill --start
```

这是离线后备，必须报告“未核验最新版本”，不能声称服务端已更新。脚本只启动与本人profile对应的本机画布，不读取别人的Key，不杀占端口程序。正常情况下按返回url打开画布；API落盘和浏览器实际显示分别核验。

把回执中的完整Skill目录注册到当前AI实际读取的用户级技能位置，支持目录链接则共用同一份；不支持时完整复制Skill和定位文件，并按官方更新工具登记已授权副本。保留原指令；当前AI之外的其他AI需要分别确认范围，不能仅写路径就声称全机AI已配置。已打开对话更新后重读，新对话实际验证发现；不能测试时注明待验证。

## 创作与画布控制

接入成功后读取 references/creative-rules.md 或官方已安装的完整规则；对模型、价格、规格、创建一次/原任务查询、后台子Agent、审核修改、反馈和充值的限制以其中规则和当前真实API合同为准。每次刷新在架/有权限模型、能力和报价，用户确认模型、宽高比/分辨率、完整费用后才生成；低价方案比较生成与超分的总费用，不保证绝对最低价。首次接入不创建真实付费任务。

用户只需提出创作需求。按语境新建或复用项目，不清楚时询问；生成成功下载作品，再通过 canvas/canvas.mjs 或 /local/v1 本机接口入板，完整合同见 canvas/AGENT.md。图片连“提示词→图片”，图生视频连“参考图片→视频”，保留最终提示词；用原任务ID和稳定节点ID去重，再执行storyboard/grid排版。画布只展示和排版，没有模型、算力或计费实现。

支持浏览器可展示的SVG、GIF和视频。SVG作为图片、不执行脚本；GIF原动图保留，缩略图可静态预览。UI视觉稿不冒充可交互前端代码。失败/未知状态先查原任务，不自动重新收费、换模型或降低规格。

后续调用先查官方Skill/画布版本，校验同源和完整性后在既有授权内更新；不覆盖Key、项目、作品、偏好、回执和其他AI指令。无可核验更新源时如实说明并保留本地版。
