# AI 创作 Skill + 本地画布

**一次对接，在自己的 AI 中生成图片、视频，并自动整理到画布。**

适合电商素材、漫剧分镜、UI 视觉稿、海报与游戏美术等创作。按当前可用模型和实时报价选择合适方案；不保证所有模型最低价或固定成功率。

## 第一次使用：只需这四步

1. **注册账号**：打开 [网站](https://erchun.youkou.cc)，完成注册并登录。
2. **打开「开放 API」**：进入 [一键 AI 对接页面](https://erchun.youkou.cc/user/open-api#api-ai-connect)。
3. **复制接入命令**：点击页面上的「复制接入命令」。不用自己抄 API Key。
4. **发给你的 AI**：把命令发给具备本机终端和文件权限的 AI，让它按仓库 Skill 完成账号接入、环境检查、技能安装及画布启动。

可以先把下面这段发给 AI：

> 请读取本仓库的 `skills/youkou-media-creator/SKILL.md`，帮我安装专属创作 Skill 和本地画布。先指导我注册并从网站复制接入命令；收到命令后完成接入。以后我要求生图、生视频时，按真实模型能力和报价确认方案，生成成功后放进画布，连接提示词与图片、参考图片与视频，并整理布局。

**接入一次后**，你可以直接说“帮我做一张电商主图”“继续这个分镜做视频”“设计一张 App 首页视觉稿”。AI会先确认模型、规格和预计完整费用，成功后保存作品并入板。

只有聊天能力、没有本机文件/终端权限的网页 AI 不能替你安装或控制本地画布；不支持时应明确说明，不能假装已完成。

## 能做什么

| 场景 | 典型用途 |
| --- | --- |
| 电商 | 商品主图、详情页配图、广告素材、商品短视频 |
| 漫剧 | 角色与场景设计、分镜图、参考图片到视频 |
| UI 设计 | 页面视觉稿、Banner、插画和界面素材；实际代码实现交给相应开发工具 |
| 其他设计 | 海报、游戏美术、概念图和视频素材 |

画布负责展示、连线、保存和排版；生成由 AI 调用你的平台 API 完成。支持图片、SVG、GIF 和浏览器可解码的视频；SVG仅作为图片加载，GIF原动画保留。AI可直接调用本机端口，无需先操作浏览器。

## 安装与运行

普通用户把仓库和网站命令发给 AI 即可。AI应先检查 Windows/Mac、架构、Python3、受支持的 Node LTS 和可用浏览器。**预构建画布不需要 npm install，也不需要浏览器插件。** 缺少运行环境时，先说明官方来源和安装内容，优先本人目录；需要管理员权限或设备审批时请用户处理，不改变既有系统环境。

```text
python scripts/onboard.py --doctor
python scripts/onboard.py
```

第二条在未接入时返回注册指引。接入后按接入工具回执运行：

```text
python scripts/onboard.py --profile <profile.json绝对路径> --install-bundled-skill --start
```

Windows可按实际环境使用 `py -3`，Mac使用 `python3`；中文/空格路径作为完整参数传入。网站命令、临时码、长期 Key 都不能提交到仓库或聊天公开区。

开发者才需要在 `canvas/` 内执行 `npm ci`、`npm run build`；运行现成包用 `node canvas/serve.mjs`。未接入时默认打开注册引导，正常创作入口由接入工具提供。项目数据默认保存在本人配置目录，与仓库、程序版本和 Git 历史分开。

## AI 控制与升级

- 当前站点、账号和 Key 独立保存；已绑定代理域名沿用该站点，不因更新切回主站。
- 本机工具：`canvas/canvas.mjs`；控制协议和排版说明见 [canvas/AGENT.md](canvas/AGENT.md)。只监听 `127.0.0.1`，不开放公网服务。
- 每次使用检查 Skill 和画布更新，同版不重复安装；只有实际公布的同源版本、校验信息和兼容范围才允许安装。更新保留作品、项目、凭据、端口和用户设置。
- 本仓库附带规则可作为明确标识的离线版本；网站未开放版本接口或网络失败时保留本地版，说明未核验最新，不能谎称已更新。不依赖重复领取一次性接入码。
- 本地注册提示可以被修改，不能作为不可绕过的授权保证；平台生成服务始终以服务端账号和 Key 校验为准。
